# Rusty Tasks — Task Manager in Rust

Rusty Tasks is a console-based application designed to manage daily and recurring tasks in a simple, clear, and reliable way.  
The project was built with a focus on modularity, unit testing, and clean development practices in Rust.  
My goal was to create a solid foundation that reflects how real-world projects are structured: separating logic, storage, and interface layers while keeping the code readable and maintainable.

---

## ✨ Main Features

- Add **daily** and **recurring** tasks  
- Mark tasks as completed  
- Delete tasks by type and index  
- Automatic counters for pending and completed tasks  
- JSON persistence for task storage  
- Full suite of **unit tests** validating the core logic inside `TaskManager`
